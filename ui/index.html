The register

This is a positive record and a priority rule, not proof of absence. An asset shown as free is an asset nobody has registered here, which is not the same as an asset nobody has pledged. Attestcoin proves that a transaction happened; it cannot prove that one did not. That is exactly how UCC-9 has governed a trillion dollar lien market for fifty years: prevention comes from priority and from the habit of checking before lending, not from omniscience.
